## English

**🌐 Live site:** <https://maszlaig.github.io/B-D-HairStudio/>

Presentation & booking website for **B&D Hairstudio** — a hair studio / barber in Hajdúszoboszló. A one-page **static** site: no server, opens in any browser, uploadable to any host. Mobile-first responsive, no build step and no framework.

**Highlights**
- **Bold, modern identity** — a light paper base with a vivid green accent and geometric all-caps headings (Syne + Manrope + Space Mono).
- **Marquee ticker** and **reveal-on-scroll** animations for a lively feel.
- **Hamburger menu** on mobile; smooth in-page navigation.
- **Direct booking & contact** — straight to Facebook and TikTok, no backend needed.
- **Work gallery** — a grid of the studio's photos.

**Tech:** vanilla HTML/CSS/JS · no framework, no build step.

**Structure:** `index.html` · `css/` · `js/` · `images/` · `dokumentumok/` (design doc PDF, HU + EN).

**Deploy:** upload the folder to Netlify / Cloudflare Pages / GitHub Pages. Full details: the **design document PDF** in `dokumentumok/`.

## Magyar

**🌐 Élő oldal:** <https://maszlaig.github.io/B-D-HairStudio/>

A **B&D Hairstudio** (hajdúszoboszlói fodrászat/borbély) bemutatkozó és időpontfoglaló weboldala. Egyoldalas, **statikus** oldal: nincs szerver, bármelyik böngészőben megnyílik, bármelyik tárhelyre feltölthető. Mobil-first reszponzív, build lépés és keretrendszer nélkül.

**Kiemelt funkciók**
- **Merész, modern arculat** — világos papír alap, élénk zöld akcentus, geometrikus nagybetűs címsorok (Syne + Manrope + Space Mono).
- **Futószöveg (marquee)** és **megjelenő-animációk** görgetéskor a lendületes hatásért.
- **Hamburger-menü** mobilon; sima oldalon belüli navigáció.
- **Közvetlen foglalás és kapcsolat** — egyenesen a Facebookra és TikTokra, backend nélkül.
- **Munka-galéria** — a szalon fotóinak rácsa.

**Technológia:** vanilla HTML/CSS/JS · keretrendszer és build lépés nélkül.

**Szerkezet:** `index.html` · `css/` · `js/` · `images/` · `dokumentumok/` (tervdokumentáció PDF, HU + EN).

**Közzététel:** töltsd fel a mappát Netlify / Cloudflare Pages / GitHub Pages tárhelyre. Teljes leírás: a **tervdokumentáció PDF** a `dokumentumok/` mappában.
